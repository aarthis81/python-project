# Campus Lost & Found

A simple web app where students post lost and found items on campus, search them, and mark them as claimed.

**Live demo:** YOUR-RENDER-LINK
**Note:** the free server sleeps when idle, so the first load can take 30 to 60 seconds.

## Features
- Post a lost or found item (name, description, location)
- Search by keyword
- Mark an item as claimed
- Works on phone and laptop

## Built with
Python, Flask, SQLite, HTML/CSS. Deployed on Render.

## Run it locally
1. `pip install -r requirements.txt`
2. `python app.py`
3. Open http://127.0.0.1:5000

## Future ideas
